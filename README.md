# Kairos — بوت تداول آلي (Trading Bot V3)

بوت تداول آلي لأزواج الفوركس والذهب، يجمع بين تحليل الأخبار بالذكاء الاصطناعي، التحليل الفني متعدد الأطر الزمنية، ونموذج XGBoost لتصفية الصفقات — قبل تنفيذها مباشرة عبر **MetaTrader5**، وإدارتها بعد الفتح عبر معمارية إدارة صفقات من ست طبقات (وقف خسارة متحرك، خروج مبني على نتيجة موزونة، جني أرباح جزئي، وغيرها).

موجّه لمن يريد تشغيل استراتيجية تداول آلية مُدارة بالكامل — من قرار الدخول إلى إدارة الصفقة وحتى الخروج — بأقل تدخل يدوي، مع مراقبة عبر تيليجرام.

> ⚠️ **تنبيه:** هذا برنامج تداول آلي يتعامل مع أموال حقيقية عبر MT5. اختبره دائماً على حساب تجريبي (Demo) أولاً. لا ضمانات ربح — راجع [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) قبل أي تشغيل حي.

---

## المزايا (Features)

- **تحليل أخبار بالذكاء الاصطناعي** — يجلب الأخبار (RSS + Finnhub)، يحلّلها عبر DeepSeek لاستخراج الاتجاه والثقة وحجم الأثر.
- **تحليل فني متعدد الأطر الزمنية** — يدمج H4 (اتجاه) وH1 (قرار) وM15 (توقيت) في تصويت موزون يحدد الاتجاه والنتيجة النهائية.
- **بوابة XGBoost قبل التنفيذ** — نموذج تعلّم آلي يُقدّر احتمالية نجاح الصفقة (`p_win`) ويرفض أي صفقة دون العتبة المحددة.
- **حساب مخاطرة ديناميكي** — حجم الصفقة يُحسب من ATR وقوة الإشارة وحالة الحساب، مع سقف صلب على المخاطرة لا يُتجاوز أبداً حتى عند التقريب لأصغر لوت.
- **إدارة صفقات من 6 طبقات** (`trade_management/`) — بعد فتح الصفقة، كل دورة تمر عبر: تحديد بروفايل الصفقة، الحماية الأولية، بوابة حوكمة المخاطر، فحص الشمعة، إغلاق فوري عند انعكاس الإشارة، نتيجة خروج موزونة، إدارة عمر الصفقة، نقل الوقف لنقطة التعادل، جني أرباح جزئي، وقف متحرك تكيّفي — كل طبقة مستقلة وقابلة للاختبار بمفردها.
- **تنفيذ مباشر عبر MT5** — لا وسيط REST؛ جلسة MT5 واحدة مشتركة بين كل الخيوط (`data/market/mt5_session.py`) تمنع تنازع الاتصال.
- **حوكمة مخاطر مستقلة** (`risk/risk_governor.py`) — يوقف الدخول في صفقات جديدة عند تجاوز حد خسارة تراكمي، بمعزل تام عن إدارة الصفقات المفتوحة.
- **مراقبة وتحكم عبر تيليجرام** — أوامر لعرض الحالة، الصفقات المفتوحة، الرصيد، آخر القرارات، إيقاف/استئناف التداول، وإغلاق طارئ لكل الصفقات.
- **تسجيل يومي دوّار** — سجلات مفصّلة (`logs/`) بدوران يومي واحتفاظ محدود، بمستوى تفصيل قابل للضبط لكل وحدة.
- **مصمم للتوسّع بأمان** — كل رقم يؤثر على قرار (أوزان، عتبات، عدد شموع، مضاعفات R) مُجمّع في ملفات config واحدة، لا مبعثر داخل الكود.

## متطلبات التشغيل (Requirements)

| المتطلب | التفاصيل |
|---|---|
| **نظام التشغيل** | Windows (مطلوب لتشغيل طرفية MetaTrader5) |
| **Python** | 3.11 أو أحدث |
| **MetaTrader5** | طرفية MT5 مثبّتة ومسجّل الدخول فيها على حساب (تجريبي أو حقيقي) لدى بروكر يدعم بايثون API |
| **مفاتيح API** | [DeepSeek](https://platform.deepseek.com) (تحليل الأخبار) · [Finnhub](https://finnhub.io) (أخبار إضافية، اختياري) |
| **بوت تيليجرام** | توكن بوت (عبر [@BotFather](https://t.me/BotFather)) ومعرّف المحادثة، للتنبيهات والتحكم عن بُعد |

> **ملاحظة:** المشروع لم يعد يعتمد على أي وسيط خارجي لبيانات السوق أو تنفيذ الأوامر — كل شيء عبر مكتبة `MetaTrader5` مباشرة (راجع `ROADMAP.md` لخلفية إزالة الاعتماد السابق على QuantDinger).

## التثبيت (Installation)

```bash
# 1. استنساخ المشروع
git clone https://github.com/gqlmyyy/kairos.git
cd kairos

# 2. تثبيت الاعتماديات
pip install -r requirements.txt

# 3. نسخ ملف البيئة وتعبئة القيم الحقيقية
cp .env.example .env
```

افتح `.env` واملأ القيم الفعلية:

```ini
# مفاتيح الذكاء الاصطناعي والأخبار
DEEPSEEK_API_KEY=sk-...
FINNHUB_API_KEY=...

# تيليجرام (للتنبيهات والتحكم)
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...

# بيانات حساب MT5
MT5_LOGIN=12345678
MT5_PASSWORD=...
MT5_SERVER=MetaQuotes-Demo
MT5_PATH=C:\Program Files\MetaTrader 5\terminal64.exe
```

⚠️ **لا تترك أي حقل فارغاً** — بعض الإعدادات الرقمية (مثل `MT5_LOGIN`) تُسقط البرنامج بالكامل عند بدء التشغيل إذا كانت القيمة فارغة بدل غائبة (راجع `KNOWN_ISSUES.md` #5).

تأكد أن طرفية MT5 مفتوحة ومسجّلة الدخول على نفس الحساب قبل تشغيل البوت.

## طريقة الاستخدام (Usage)

### تشغيل البوت

```bash
python main.py
```

عند البدء، يتحقق البوت من جلسة MT5، يشغّل خيوط المراقبة الخلفية (تيليجرام، مراقب اتصال MT5، تسوية الصفقات، مدير إدارة الصفقات)، ثم يدخل حلقة القرار الدورية (كل 30 دقيقة افتراضياً، `NEWS_CHECK_INTERVAL` في `config.py`).

راقب أول الأسطر في السجل للتأكد أن الجلسة قامت بنجاح:
```
[MT5_SESSION] connected login=... server=... balance=...
```

### أوامر تيليجرام أثناء التشغيل

| الأمر | الوظيفة |
|---|---|
| `/status` | حالة البوت والدورات ونتائج اليوم |
| `/positions` | الصفقات المفتوحة حالياً |
| `/balance` | الرصيد والهامش من MT5 مباشرة |
| `/why` | آخر 5 قرارات وأسبابها |
| `/report` | تقرير الأداء اليومي |
| `/pause` , `/start_trading` | إيقاف/استئناف الدخول في صفقات جديدة |
| `/emergency` | إغلاق كل الصفقات المفتوحة فوراً |
| `/analyze <symbol>` | تحليل فوري لرمز معيّن دون انتظار الدورة |

### تشغيل الاختبارات

```bash
pytest tests/ -q
```

يغطي أكثر من 200 اختبار: طبقات إدارة الصفقات الست، حساب حجم الصفقة وحدود المخاطرة، جلسة MT5، ومصادر بيانات السوق. اختبار واحد فقط يفشل عمداً كبوابة أمان (`test_predict_proba_parity.py`) طالما نموذج الخروج غير متوافق مع مخطط الخصائص — راجع `KNOWN_ISSUES.md` #2.

## إعدادات التهيئة (Configuration)

| الملف | الغرض |
|---|---|
| `.env` | أسرار وبيانات الاتصال (مفاتيح API، بيانات حساب MT5، تيليجرام) — **لا يُرفع لأي مستودع** |
| `config.py` | كل الإعدادات التشغيلية: الرموز المتداولة، أوزان التصويت، حدود المخاطرة، فترات الدورات، مستويات السجل |
| `trade_management/tm_config.py` | كل رقم تستخدمه طبقات إدارة الصفقات الست (أوزان نتيجة الخروج، عتبات الوقف المتحرك، سلّم جني الأرباح الجزئي، إعدادات كل بروفايل صفقة) |

أهم الإعدادات في `config.py`:

```python
SYMBOLS = ["EURUSD", "XAUUSD", "GBPUSD"]   # الأزواج المتداولة
BASE_RISK_PERCENT = 0.005                   # مخاطرة أساسية 0.5% لكل صفقة
MAX_RISK_PER_TRADE_PCT = 0.02               # سقف صلب 2% — لا يُتجاوز أبداً
MAX_OPEN_TRADES = 3
RISK_GOVERNOR_MAX_LOSS_R = 6.0              # يوقف الدخول بعد خسارة 6R تراكمية
ML_EXIT_ENABLED = False                     # نموذج الخروج معطّل — راجع ROADMAP.md
```

## هيكل المشروع (Project Structure)

```
kairos/
├── main.py                    # نقطة البدء — حلقة القرار الرئيسية
├── config.py                  # الإعدادات المركزية
├── trade_management/          # الطبقات الست لإدارة الصفقات بعد الفتح + المنسّق
├── decision/                  # التصويت الموزون وحساب الثقة
├── risk/                      # حجم الصفقة، حوكمة المخاطر، معلومات الرمز
├── execution/                 # تنفيذ الأوامر عبر MT5، التسوية، مراقب الاتصال
├── analysis/                  # تحليل الأخبار (DeepSeek)، المشاعر، النماذج، خط تدريب entry_v2
├── data/                      # بيانات السوق (MT5)، الأخبار، قاعدة البيانات
├── feedback/                  # تعلّم الأوزان من أداء الصفقات السابقة
├── telegram/                  # بوت التيليجرام والتنبيهات
├── core/                      # نماذج بيانات مشتركة، سياق الدورة، نبض القلب
├── scripts/                   # سكربتات تدريب النماذج وبناء datasets
├── tests/                     # اختبارات الوحدة (pytest)
├── KNOWN_ISSUES.md            # مشاكل معروفة موثّقة عمداً، بموقعها وسببها
└── ROADMAP.md                 # عمل مؤجَّل عمداً (إعادة تفعيل نموذج الخروج، تحسينات الأداء)
```

للتوثيق الكامل الأعمق لكل قرار هندسي ولماذا اتُّخذ، راجع `KNOWN_ISSUES.md` و`ROADMAP.md`.
